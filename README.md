# 🏡 Smart-Nest — Smart Home Website

A modern, static smart home website built with **HTML and CSS**, designed to present smart home solutions through a clean layout and an engaging visual experience.

## 📌 About the Project

**Smart-Nest** is a frontend web development project focused on smart home living and interior inspiration. It provides a website interface for exploring furniture, home interiors, and smart home concepts.

The project demonstrates the use of core web technologies to create a structured, visually appealing, and easy-to-navigate website.

## ✨ Features

- 🏠 **Smart Home Theme** — A website centered around modern home living.
- 🛋️ **Furniture Section** — Showcases furniture and home furnishing ideas.
- 🎨 **Interior Design Inspiration** — Presents interior ideas for different home spaces.
- 🖼️ **Image Gallery** — Uses images to enhance the website's visual appeal.
- 📱 **Frontend Design** — Built with HTML and CSS.
- ⚡ **Static Website** — No backend or database required.

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layout, and visual design |
| Images | Visual content and design inspiration |
| Git & GitHub | Version control and project hosting |

## 🚀 Getting Started

You can run this project locally in just a few steps.

### 1. Clone the repository

```bash
git clone https://github.com/mayaankhan/Smart-Nest.git
```

### 2. Navigate to the project folder

```bash
cd Smart-Nest
```

### 3. Open the website

Open `Furniture.html` in your preferred web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension to preview the website.
